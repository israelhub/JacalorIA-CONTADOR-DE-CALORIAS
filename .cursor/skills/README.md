# Skills do Cursor

Skills versionadas neste repositório, copiadas do [figma/mcp-server-guide](https://github.com/figma/mcp-server-guide) no GitHub.

## `figma-generate-diagram`

Skill oficial da Figma para gerar diagramas no FigJam a partir de Mermaid (`generate_diagram`). Inclui referências por tipo: flowchart, architecture, sequence, ERD, state e gantt.

## `figma-use-figjam`

Skill complementar exigida pelo fluxo híbrido da generate-diagram (anotações, cores e elementos nativos do FigJam depois da geração).
